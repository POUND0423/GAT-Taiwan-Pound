# 信義漫遊公開版

在專案根目錄執行 `node outputs/xinyi-walk/server.cjs`，或在 Windows 雙擊「開啟街景.cmd」。需要 PATH 中的 Node.js。開啟 http://127.0.0.1:8765/，僅供本機存取。

- 城市鳥瞰：拖曳旋轉、滾輪縮放、右鍵平移。
- 街道漫遊：WASD／方向鍵移動、Shift 加速、滑鼠或拖曳轉頭；Esc 解除鎖定。
- 觸控裝置：方向按鈕移動、拖曳場景轉頭。
- 台北 101：快速定位至南側街道。
- 日照滑桿及陰影：示意光照；不是精確天文模擬。

本版本有 1,166 個 OSM 建築／分段、1,144 個地面碰撞多邊形、小地圖、程序化外牆與天空。沒有駕駛、打鬥、路人或任務。地面平坦、道路寬度示意、建築高度可能由樓層估算。

地圖及材質為本機生成的公開版 PNG，不包含衛星照片、外掛貼圖或 Blender 場景。資料 © OpenStreetMap contributors，ODbL 1.0；Three.js r180 為 MIT。來源見根目錄 ATTRIBUTION.md。

不要雙擊 `index.html`；瀏覽器的本機檔案限制可能阻擋模組及 JSON 載入。關閉伺服器終端機後，網址即停止服務。
